WELCOME TO RAINMASTER

Rainmaster helps you visually design Rainmeter skins and export them as ready-to-use packages. Here's a quick tour:

1
Add Elements

Use the left toolbar to add shapes, text, and images. Click any tool to place an element on the canvas.

2
Edit Properties

Select an element and use the right panel to change position, size, colors, fonts, and more. Everything updates in real-time.

3
Organize with Layers

Switch to the Layers tab to reorder elements, toggle visibility, or lock them in place.

4
Add Measures & Variables

Use the Measures and Vars tabs to add dynamic data. Reference variables with #varName# in any property.

5
Upload Images

For image meters, use the file upload in properties. Images are stored locally and exported to the @Resources folder.

6
Export Your Skin

Click Export to download a .zip file containing your .ini and all images in the correct folder structure.
